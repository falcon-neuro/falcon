# Falcon

Falcon is a modular and extensible software framework for soft real-time signal processing, originally designed for short-latency closed-loop neural applications. Its new engine extends this to high channel counts at high data rates: hundreds of channels sampled at 30 kHz, processed sample by sample on a standard CPU.

Documentation: <https://falcon-neuro.org/docs>

## Status

A new engine is in development. Installation instructions will follow with its first release.

## Origins

Falcon began with the work of Davide Ciliberti and Fabian Kloosterman, who introduced it in:

Ciliberti D, Kloosterman F (2017). Falcon: a highly flexible open-source software for closed-loop neuroscience. *Journal of Neural Engineering* 14, 045004. <https://doi.org/10.1088/1741-2552/aa7526>
